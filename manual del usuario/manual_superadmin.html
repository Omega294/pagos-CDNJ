Sección 1

Perfil Superadmin

👑
Acceso Irrestricto Total El perfil SUPERADMIN tiene acceso implícito a todas las funcionalidades del sistema mediante el permiso wildcard *. No existen restricciones de acceso para este perfil. Actúa con máxima responsabilidad.

El Superadmin es el nivel más alto de autoridad en el sistema CDNJ. Su función es la configuración global de la plataforma, gestión de usuarios y roles, y supervisión de todos los módulos del sistema.

Sección 2

Acceso y Seguridad de la Cuenta

🚨
Cuenta de Máxima Sensibilidad La cuenta SUPERADMIN tiene acceso total al sistema. Su compromiso puede resultar en la pérdida o modificación de todos los datos financieros del colegio. Protege las credenciales con máxima prioridad.
1

Contraseña Robusta Obligatoria

La contraseña del Superadmin debe ser de al menos 16 caracteres, combinando mayúsculas, minúsculas, números y símbolos especiales. Cámbiala periódicamente (mínimo cada 90 días).

2

Acceso Exclusivo y Personal

Nunca compartas las credenciales de Superadmin con otras personas, ni siquiera con administradores. Si alguien más necesita capacidades elevadas, créale una cuenta propia con los permisos apropiados.

3

Cerrar Sesión Siempre

Al terminar cualquier tarea, cierra sesión usando el botón de LogOut en la barra superior. Nunca dejes la sesión de Superadmin abierta sin supervisión.

4

Monitorear el Log de Acciones

Como Superadmin, tienes acceso a los logs del sistema. Revisa periódicamente las acciones realizadas por todos los usuarios para detectar actividades sospechosas.

⚡
Sección 3

El Permiso Wildcard (*) – Acceso Total

El sistema CDNJ implementa RBAC (Role-Based Access Control) granular. El Superadmin posee el permiso especial * (wildcard) que bypasea todas las verificaciones de permisos.

🌟 Permiso Wildcard

⚡ * (Control Total Implícito)

Este único permiso equivale a tener todos los permisos posibles del sistema, presentes y futuros. Al agregar nuevos módulos al sistema, el Superadmin tendrá acceso automático sin necesidad de configuración adicional.

ℹ️
Implementación Técnica: En el sistema, la verificación de permisos primero comprueba si el usuario tiene el rol SUPERADMIN o el permiso *. Si es así, la verificación retorna true inmediatamente sin evaluar permisos específicos.

Sección 7

Buenas Prácticas para el Superadmin

🔐 Principio de Mínimo Privilegio

Aunque puedes otorgar cualquier permiso, sigue el principio de mínimo privilegio: asigna a cada usuario solo los permisos estrictamente necesarios para su función. Evita crear muchos usuarios con rol Administrador innecesariamente.

📝 Documentar Cambios de Configuración

Cada vez que modifiques configuraciones críticas (aranceles, roles, permisos), documenta el cambio con fecha, motivo y usuario responsable. Mantén un registro externo de los cambios de configuración para auditorías.

🧪 Probar en Entorno Demo Primero

Si vas a realizar cambios importantes al sistema (nuevos conceptos de pago, cambios de roles), primero verifica su funcionamiento en el entorno demo antes de aplicarlos en producción.

🚨 Revisión Periódica de Usuarios

Realiza una revisión mensual de todos los usuarios activos del sistema. Desactiva inmediatamente las cuentas de empleados que ya no trabajan en la institución para prevenir accesos no autorizados.

Sección 8

Arquitectura RBAC del Sistema

El sistema CDNJ implementa RBAC Granular (Role-Based Access Control). Cada función está protegida por un permiso específico con el formato módulo:submodulo:acción.

PermisoMóduloFunción
payments:cashier:create_payment Cobros Registrar nuevos pagos en caja
payments:cashier:search_students Cobros Buscar alumnos y ver sus deudas
payments:cashier:view_receipt Cobros Ver e imprimir recibos emitidos
payments:admin:view_history Admin Acceder al historial de transacciones
payments:admin:void_receipt Admin Anular recibos con motivo documentado
payments:admin:close_box Admin Ejecutar cierre de caja diario
payments:config:manage_rates Config Actualizar tasa de cambio y ver aranceles
* GLOBAL Todos los permisos (solo Superadmin)
ℹ️
Extensión del Sistema RBAC: Al agregar nuevos módulos al sistema (Calificaciones, Matrículas, Asistencia), se crearán nuevos permisos con el mismo esquema modulo:submodulo:accion. El Superadmin tendrá acceso automático por su permiso wildcard *.
